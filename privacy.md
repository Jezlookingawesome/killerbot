Privacy Policy — Killer Bot

Last updated: 09/13/2026

This Privacy Policy explains what data Killer ("the Bot") collects, how it's used, and how it's stored.

1. What we collect
The Bot processes the following data while running:

· Discord user IDs, server IDs, and channel IDs — used to track which users are "murdered" in each server
· Message content — read only to detect commands (messages starting with !) and to apply the "murdered" effect
· User display names and profile pictures — used when reposting a murdered user's message via webhook

2. How we use it
This data is used solely to operate the Bot's features (murder, unmurder, gamble, etc.). It is not sold, shared, or used for advertising.

3. Storage
The Bot does not use a database. The list of "murdered" users is kept in memory only and is cleared whenever the Bot restarts. No message content is permanently stored.

4. Third-party services
The Bot uses a third-party API (some-random-api.com) to generate greyscale versions of user profile pictures. Only the user's public Discord avatar URL is sent to this service. No other data is shared.

5. Logging
Basic runtime logs (errors, startup messages) may be visible to the Bot's developer through its hosting provider. These logs do not contain message content and are deleted automatically by the host.

6. Data removal
Because the Bot stores no persistent data, there is nothing to delete. Restarting the Bot clears all in-memory state.

7. Children
The Bot is not directed at children under 13. Use of Discord is subject to Discord's own age requirements.

8. Changes
This policy may be updated at any time. Continued use of the Bot after changes means you accept the new policy.

9. Contact
For questions, contact the bot owner via the support server or the developer's Discord account.
